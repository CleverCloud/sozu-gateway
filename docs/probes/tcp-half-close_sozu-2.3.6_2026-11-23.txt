bind-mounted from the host, 2 workers. The TCP listener, cluster, backend and frontend were added
with Sozu's own CLI inside the container (`docker exec ... sozu -c /etc/sozu/config.toml <args>`;
the commands are echoed below without the `-c`, their stdout indented). The 2.3.6 CLI prints
"Logs will be sent to stdout", "Access logs will be sent to None" and "Success: ..." on stdout
(stderr was empty), lines the 2.3.2 record does not show. The backend is a Python echo server on
127.0.0.1:31690. The client sends one line, then either shuts down its write side (`halfclose`,
what `printf | socat -` does at stdin EOF) or keeps it open (`keepopen`, what `socat -,ignoreeof`
does), and prints what it receives within 3 s. The last two lines are the controls against the
backend directly. The container and the echo server were removed after the run. Client and echo
backend are byte-identical to the 2.3.2 record's; only the ports moved into a range reserved for
this run (proxy 38680 -> 31680, backend 38690 -> 31690). Python 3.12.3. Probe source: ad hoc
(no in-repo example), the scripts below; harness at 8923b4a's tree, nothing in it changed.

Client (hc-client.py):

import socket, sys, time
port = int(sys.argv[1]); mode = sys.argv[2]
s = socket.create_connection(("127.0.0.1", port)); s.settimeout(3)
s.sendall(b"hello-tcp\n")
if mode == "halfclose":
    s.shutdown(socket.SHUT_WR)  # client sends, then shuts its write side (stdin EOF in `socat -`)
out = b""
start = time.monotonic()
try:
    while True:
        d = s.recv(4096)
        if not d: break
        out += d
        if mode != "halfclose" and out.endswith(b"\n"): break
except socket.timeout:
    pass
print(f"{mode}: received {out!r} after {time.monotonic() - start:.3f} s")

Echo backend (hc-echo.py):

import socket, sys, threading
port = int(sys.argv[1])
srv = socket.socket(); srv.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
srv.bind(("127.0.0.1", port)); srv.listen(64)
def h(c):
    try:
        while True:
            d = c.recv(4096)
            if not d: break
            c.sendall(d)
    finally: c.close()
while True:
    c, _ = srv.accept(); threading.Thread(target=h, args=(c,), daemon=True).start()
